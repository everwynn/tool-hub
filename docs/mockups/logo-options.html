每个方案展示四组场景：Header 实景（浅色 / 深色）、品牌图标尺寸阶梯（16→64px）、浏览器标签页 favicon 模拟（浅色 / 深色）。 评估重点：「工具集合」语义是否一眼可读、小尺寸是否清晰、与站点绿色视觉是否协调。

现状：播放圆圈（play-circle）

方案 A：模块矩阵

2×2 圆角方块，第四块用虚线表示「持续新增的工具」——语义即「多个工具的集合」， 与首页「分类总览卡」的圆角方块是同一套视觉语言；几何极简，16px 下依然清晰。
